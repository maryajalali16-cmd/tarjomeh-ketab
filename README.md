## هدف پروژه
تولید محتوای آموزشیِ مستقل و دقیق برای آمادگی درس رفتار سازمانی در سطح MBA، همراه با واژه‌نامهٔ تعاملی و رابط مطالعهٔ HTML.

> این پروژه ترجمهٔ کامل یا بازتولید متن کتاب نیست. محتوای فارسی به‌صورت توضیح، تحلیل، مثال، نقشهٔ مفهومی، مرور امتحانی و پرسش‌های تألیفی تهیه می‌شود. نقل‌قول مستقیم از کتاب به حداقل ضروری محدود می‌ماند.
