# راهنمای آموزشی رفتار سازمانی برای MBA

این مخزن برای تدوین یک راهنمای فارسی آموزشی و تحلیلی بر اساس ساختار کتاب *Essentials of Organizational Behavior*، ویرایش چهاردهم، Global Edition (Robbins & Judge) ایجاد شده است.

> این پروژه ترجمهٔ کامل کتاب یا جایگزین متن اصلی نیست؛ توضیح‌ها، کاربردهای مدیریتی و تمرین‌ها به‌صورت تألیفی تدوین می‌شوند.

## ساختار پروژه
- `content/`: درس‌نامه‌ها و خوانشگر
- `glossary/`: واژه‌نامه و سیاست اصطلاح‌شناسی
- `prompts/`: پرامپت مرجع تدوین
- `docs/`: منشور، نقشهٔ کتاب، مشخصات خوانشگر، کنترل کیفیت و گزارش پیشرفت
