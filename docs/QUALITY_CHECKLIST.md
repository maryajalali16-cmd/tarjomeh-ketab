# چک‌لیست کنترل کیفیت

## علمی
- [ ] همهٔ مفاهیم با فصل و بخش متناظر منبع قابل ردیابی‌اند.
- [ ] تعریف‌ها با نظریه‌ها و مدل‌های مشابه خلط نشده‌اند.
- [ ] پیش‌فرض‌ها و محدودیت‌ها حذف نشده‌اند.
- [ ] هیچ نتیجهٔ پژوهشی یا ارجاعی جعل نشده است.
- [ ] مثال‌های افزوده به‌وضوح تألیفی‌اند.

## آموزشی و امتحانی
- [ ] تمایزهای مفهومی مهم روشن‌اند.
- [ ] دست‌کم یک کاربرد مدیریتی معنادار وجود دارد.
- [ ] پرسش‌های تحلیلی و موردکاوی وجود دارند.
- [ ] پاسخ نمونه استدلال دارد، نه صرفاً فهرست‌کردن تعریف‌ها.
- [ ] خطاهای رایج و دام‌های مفهومی مشخص شده‌اند.

## واژگان و HTML

- [ ] تولتیپ با hover، focus و لمس قابل دسترسی است.
- [ ] جست‌وجو و ناوبری درست کار می‌کنند.
